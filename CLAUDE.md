# Rizoma - Claude Code Guide

Rizoma is Daniel's personal note-taking app — a hard fork of Reflect V2, now fully
detached from it. The code still says "reflect" everywhere (packages, crates, CLI,
bundle ids); only the docs carry the new name. That's expected, not a migration in
progress.

See [AGENTS.md](AGENTS.md) for the project overview, the fork's history and what it
implies, product principles, repo layout, dev commands, and code conventions.

Read ALL of it before starting ANY work. This is VERY important. You must read
AGENTS.md in its entirety before continuing.
